# Satbond Website

Official corporate landing page and product showcase website for Satbond professional-grade adhesives.

## Tech Stack

- **Framework**: React 19 & TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4

## Features

- **Product Showcase**: Detailed breakdown of Satbond V7, HV Gel, Woodfill, Spray Activator, and Debonder.
- **Scroll-Driven Interactive Navigation**: Smooth section locking and step-by-step progress highlights.
- **Application Finder**: Multi-surface recommendations for woodworking, footwear, jewellery, automotive, and hardware repairs.
- **Responsive Design**: Mobile and desktop optimized UI layouts.
- **Partner & Dealer Portal**: Information and enquiry CTA for pan-India dealership opportunities.

## Getting Started

First, install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

## Build

To create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
